# IstraArt — мастерская природного дерева

**IstraArt** — авторские предметы интерьера из природного дерева. Мастерская в Истре, вдохновлённая находками на берегах Истринского водохранилища.

**Идея:** искусство, созданное природой и раскрытое человеком.  
**Рабочий слоган:** «Природа создаёт форму. Мы раскрываем её красоту».

## Легенда бренда

Мастерская IstraArt рождается на берегах Истринского водохранилища. Её основатель живёт на Истре в доме из сухарника, любит натуральное дерево и часто гуляет вдоль берега, где находит необычные коряги, старые корни и другие выразительные фрагменты древесины.

Вода, ветер, солнце и время придают дереву неповторимые изгибы, фактуру и цвет. В мастерской эти находки превращаются в светильники, скульптуры, подставки и другие предметы интерьера. Задача мастера — не скрыть природную форму, а подчеркнуть её.

**Каждая работа уникальна: природа не создаёт двух одинаковых коряг.**

Эта легенда — исходная концепция, которую можно развивать по мере появления реальных изделий и фотографий процесса.

## Три направления проекта

1. **Готовые изделия.** Светильники, подсвечники, подставки, настенный и напольный декор, арт-объекты, небольшая мебель, индивидуальные заказы.
2. **Природные заготовки.** Выразительные коряги, спилы, корни, фрагменты дерева для мастеров, дизайнеров и DIY.
3. **DIY-гайды.** Инструкции по самостоятельному изготовлению; первоначально обсуждалась цена **500 ₽** за гайд, без подтверждения коммерческой модели.

### Возможные категории каталога

- Светильники: настольные, напольные и настенные.
- Подсвечники и подставки для растений.
- Скульптуры, декоративные объекты из коряг, корней и спилов.
- Малые предметы мебели: столики, полки, консоли.
- Природные заготовки и DIY-инструкции.
- Изделия по индивидуальному заказу.

Список — ассортиментная концепция, а не утверждение о наличии готовых изделий.

## Зафиксированный логотип

Фирменный знак IstraArt — **четыре концентрических круга**: три контурных кольца и центральная точка. Он используется слева от надписи **IstraArt** в шапке сайта (исходная реализация — `components/site-header.tsx`, компонент `Logo`). Фавикон — **тот же знак без надписи**, в `public/icon.svg`, цвет древесный. При дальнейших изменениях не заменять знаком v0 или иным рисунком; менять логотип только по отдельному согласованию.

## Бренд и визуальная подача

Натуральная форма дерева, тактильные текстуры, ручной труд, скандинавский минимализм, japandi, спокойная премиальная подача. Палитра: молочный, песочный, древесный, тёплый серый, графит. Крупные предметные и интерьерные фотографии, много воздуха и минимум лишнего текста.

**Основной визуальный формат — реальные фотографии.** Идею вращающегося 3D-видео отложили: не включать в текущий MVP.

## Продвижение и OLNOO Content Factory

Цель: одна карточка/публикация для сайта, Telegram, VK, Instagram, Pinterest и Авито, без повторного ручного ввода.

Планируемый путь:

`Фото + название + описание + цена в Telegram → OLNOO Content Factory → редактура ИИ + Quality Gate → подтверждение → публикация в доступных каналах`

После проверки на реальных товарах: автопубликация только при успешном Quality Gate, остальные материалы — на ручное подтверждение.

- **OLNOO Admin:** отдельный проект с slug `istraart`.
- **Бот приёма:** `@olnoo_social`; фото и текст уже попадали в «Контент-завод → Материалы».
- **Текущая доработка:** собственные товары должны получать короткие продающие тексты, а не аналитическую переработку новостей; описание, цена и оригинальные фото сохраняются.
- **Telegram, VK:** задействовать существующий модуль Social после настройки каналов проекта.
- **Instagram, Pinterest:** планируемые каналы; возможность и права публикации через API необходимо проверять отдельно.
- **Авито:** планируемый канал объявлений; сначала проверить доступную для аккаунта автозагрузку/XML или API и её тарифные условия.
- **Сайт:** отдельный канал публикации карточек; **OLNOO — предполагаемый единый источник каталога**, а не ещё одна копия, которую нужно заполнять вручную.

**Не считать эти интеграции готовыми только потому, что они перечислены здесь.**

## Разработка — принятые правила

1. GitHub — единственный source of truth; не редактировать production вручную.
2. Сначала дизайн/MVP, потом данные каталога и интеграция с OLNOO, затем расширение каналов.
3. Не добавлять лишнюю базу данных и сервисы до доказанной необходимости; использовать существующие модули OLNOO.
4. Не смешивать изменения дизайна, бизнес-логики, деплоя и инфраструктуры в одном PR.
5. Не хранить секреты и тяжёлые фото/видео в Git.
6. Для техзадач OLNOO перед работой читать `AGENTS.md`, `OLNOO_PROJECT_MAP.md`, `OLNOO_ARCHITECTURE.md` **если эти файлы есть в соответствующем репозитории**; если меняются системные факты — обновлять документацию в том же commit.
